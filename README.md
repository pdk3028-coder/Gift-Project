# 사원 정보·선물 배송지 관리

사번과 개인정보 이용 동의로 로그인하는 기존 방식을 유지합니다. 관리자 기능은 별도 비밀번호로 보호합니다.

## 설치와 실행 (Windows, Python 3.11 이상)

**원클릭 실행:** `run_program.bat`를 더블클릭하세요. 필요한 환경을 준비하고 서버가 응답하면 기본 브라우저를 자동으로 엽니다. 이미 실행 중이면 서버를 추가 실행하지 않고 브라우저만 엽니다. 사용 중에는 서버 창을 유지하고, 종료하려면 서버 창에서 Ctrl+C를 누르거나 창을 닫으세요. 설치가 5분 이상 걸려 자동 열기 대기가 끝났다면 준비 완료 후 배치 파일을 다시 실행하면 됩니다.

`start_server.bat`를 실행하면 가상환경과 필수 패키지가 없을 때 자동으로 준비합니다. 처음에는 인터넷 연결이 필요합니다. 설치된 Python을 우선 사용하고, 이 PC에서는 사용 가능한 Codex 번들 Python도 찾습니다. 준비가 끝나면 표시된 주소를 브라우저에서 여세요. 수동 설치를 원하는 경우 다음 명령을 사용합니다.

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

기존 `employees.db`가 있으면 기존 관리자 비밀번호를 사용합니다. 신규 설치 또는 비밀번호 복구는 서버 컴퓨터에서 다음 명령을 실행하세요. 입력은 화면에 표시되지 않습니다. 기본 비밀번호는 생성하지 않습니다.

```powershell
.venv\Scripts\python.exe -m flask --app app set-admin-password
```

비밀번호는 8~128자입니다. `start_server.bat`를 실행한 뒤 브라우저에서 `http://127.0.0.1:5000`을 엽니다. Waitress 서버가 실행되며 창에서 Ctrl+C로 종료합니다. 디버그 모드는 사용하지 않습니다.

## 변경 사항과 호환성

- DB 경로는 실행 위치와 관계없이 프로젝트의 `employees.db`입니다. `GIFT_DATABASE`로 절대 경로를 지정할 수 있습니다.
- 최초 실행 시 `instance/secret.key`에 무작위 서명 키를 저장하고 재시작 시 재사용합니다. `instance/`는 Git에서 제외됩니다. 해당 폴더와 DB의 Windows 접근 권한을 서버 운영 계정으로 제한하세요. `GIFT_SECRET_KEY` 환경변수로 32자 이상의 무작위 키를 지정할 수도 있습니다. 키를 바꾸면 기존 로그인 세션이 무효화됩니다. 첫 보안 업데이트에서도 기존 사용자는 다시 로그인해야 합니다.
- 세션 유효기간은 30분이며 모든 변경 요청에는 CSRF 토큰이 필요합니다. 오래 열어 둔 화면에서 오류가 발생하면 새로고침 후 다시 로그인하세요. 관리자 비밀번호 변경 시 다른 관리자 세션은 무효화됩니다.
- '수정 없음'을 체크하면 서버는 입력창의 변경값을 무시하고 기존 값을 보존합니다. 선물 배송지가 처음 등록되는 경우 화면에 표시된 인사 주소를 저장합니다.
- 선물 삭제는 선택 목록에서 제외하는 동작입니다. 기존 선택 기록과 다운로드의 선물명은 유지합니다. 이미 제외된 선물을 다시 제출할 수 없습니다.
- 데이터 초기화는 사원·선물 데이터와 기능 설정을 삭제하지만 관리자 비밀번호는 보존합니다. 초기화는 되돌릴 수 없으므로 먼저 백업하세요.
- 업로드 요청은 최대 10MB입니다. 선물 이미지는 JPEG/PNG/WebP, 최대 1,600만 화소이며 서버가 JPEG로 다시 저장합니다. HTML/SVG는 등록할 수 없습니다.
- 엑셀 다운로드는 메모리에서 생성합니다. 모든 DB 문자열을 텍스트 셀로 저장해 수식 실행을 방지하고 사번·우편번호의 선행 0을 보존합니다.

## 명부 업로드

첫 시트의 첫 행이 열 이름이어야 합니다. 기존 명부의 `사번`, `성명`, `핸드폰`, `현거주지`, `우편번호-현`을 지원합니다. 열 순서는 자유이며 추가 열은 무시합니다. 영문 `emp_id`, `name`, `phone`, `address_main`, `zipcode`도 지원합니다. 전체 별칭은 `database.py`의 `IMPORT_COLUMNS`를 참고하세요.

필수 열이 없거나 중복되면 전체 업로드를 거부합니다. 데이터는 1~20,000행이며 사번·성명은 필수, 사번 중복은 허용하지 않습니다. 명부의 우편번호는 공란, 5자리 또는 기존 6자리 숫자를 허용합니다. 기존 `123-456` 형식은 하이픈만 제거하고 보존하며, 주소 확인 없이 새 5자리 번호로 추정 변환하지 않습니다. 화면에서 주소를 새로 입력할 때는 주소 검색으로 받은 5자리 번호를 사용합니다. 사번과 우편번호는 원본 엑셀에서도 텍스트 형식으로 저장하세요. 숫자 셀에서 이미 사라진 선행 0은 복원할 수 없습니다.

모든 행을 검증한 후 한 트랜잭션으로 저장합니다. 기존 사원의 연락처·주소·우편번호는 업로드 셀이 비어 있으면 보존합니다. 선물 선택과 배송지, 상세 주소도 보존합니다. 업로드 원본은 임시 폴더에서 처리한 뒤 성공·실패 모두 삭제합니다. 잘못된 파일에 대한 상세 서버 경로는 화면에 노출하지 않습니다.

## 배포 설정

GiftPoongsan 계정의 PythonAnywhere 배포 절차는 [PYTHONANYWHERE.md](PYTHONANYWHERE.md)를 참고하세요. 전용 WSGI 진입점이 HTTPS 쿠키와 영구 데이터 경로를 설정합니다.

기본 서버는 `127.0.0.1:5000`에서 실행됩니다. `GIFT_HOST`, `GIFT_PORT`로 변경할 수 있습니다. 외부 서비스는 HTTPS를 제공하는 역방향 프록시 뒤에 배치하고 `GIFT_HTTPS=1`을 설정하세요. 로컬 HTTP에서 이 값을 켜면 보안 쿠키가 전송되지 않습니다.

기본값은 `X-Forwarded-For`를 신뢰하지 않습니다. 신뢰할 수 있는 프록시만 서버에 접속하도록 방화벽을 구성하고 프록시가 전달 헤더를 덮어쓰는 경우에만 `GIFT_TRUSTED_PROXY_HOPS`에 정확한 프록시 수를 지정하세요. 임의의 인터넷 요청이 서버에 직접 도달하는 상태에서 켜지 마세요.

기본 요청 제한 저장소는 단일 Waitress 프로세스의 메모리입니다. 프로세스 재시작 시 제한 카운터가 초기화됩니다. 여러 프로세스/서버를 운영할 때는 `GIFT_RATE_LIMIT_STORAGE`에 공유 Redis URI를 지정하고 해당 배포 환경에 `flask-limiter[redis]` 지원 의존성을 설치하세요. 일반 사번 로그인 방식과 전체 사용자 접속 제한 해제 정책은 유지합니다.

## 오래된 파일 정리

기존 사원 명부·추출 파일은 이번 업데이트에서 자동 삭제하지 않습니다. 다음 명령으로 `uploads/`의 엑셀 파일과 DB에서 참조하지 않는 선물 이미지를 확인할 수 있습니다.

```powershell
.venv\Scripts\python.exe -m flask --app app cleanup-uploads
```

필요한 자료를 별도 백업한 후 서버를 중지하고 `--apply`를 붙여 삭제하세요. 삭제된 선물의 이미지도 과거 기록에서 참조 중이면 보존합니다. 프로젝트 루트에 직접 둔 원본 명부는 이 명령의 대상이 아닙니다. 루트 원본 파일은 보관 필요 여부를 확인해 별도로 관리하세요.

## 백업과 복구

1. 서버를 중지합니다.
2. `employees.db`, `uploads/gift_images/`, `instance/secret.key`를 접근이 제한된 백업 위치에 함께 복사합니다. 외부 환경변수로 키를 관리한다면 해당 키도 안전하게 보관합니다.
3. 복구할 때 서버가 중지된 상태에서 같은 위치에 백업을 복사하고 서버를 다시 실행합니다.
4. 관리자 로그인, 사원 정보, 선물 이미지 및 엑셀 다운로드를 확인합니다. 관리자 비밀번호만 잊었다면 DB 초기화 대신 `set-admin-password` 명령을 사용합니다.

첫 실행 시 DB 구조 검사와 기존 누락 선물 참조 정리가 수행됩니다. 업데이트 배포 전에도 동일한 백업 절차를 적용하세요.

## 회귀 테스트

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

테스트는 임시 DB·임시 이미지 폴더·가상 사원만 사용합니다. 인증 위조, 경로 이탈, CSRF, 제한 우회, 엑셀 수식·형식 검증, 초기화, 선물 기록, HTML 폼, 정리 명령을 확인합니다. 실제 DB를 테스트 대상으로 지정하지 마세요.
